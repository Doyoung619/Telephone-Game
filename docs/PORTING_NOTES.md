# 코드 정리 범위

이 저장소는 로컬에서 실행한 기존 실험의 코드를 옮긴 것이다. 새 순서 선택 방법이나 번역 실험을 추가하지 않았으며 기존 측정 결과를 배포하지 않는다.

정리한 내용:

- 실험 실행·평가·분석을 `pipeline/`, 순서 알고리즘·프롬프트·다운로더를 `reference/`에 모았다.
- 특정 사용자의 홈 디렉터리와 다른 프로젝트의 Python 환경에 대한 의존을 제거했다.
- 그림 출력 경로를 저장소 내부 `artifacts/Review/`로 통일했다.
- 모델/데이터 revision을 고정하고 준비·검증 CLI와 설치 스크립트를 추가했다.
- 원래 별도 생성했던 외부 refit 사전 등록 파일을 준비 단계에서 만들도록 연결했다. 외부 test가 이미 있으면 사후 등록을 거부한다.
- 재시작 시 편집 카운터와 단계 시간이 사라지지 않도록 SQLite 메타데이터와 단계 기록을 유지한다.
- 모델을 로딩하지 않는 mock 검사와 분할/정보 접근 경계/재학습 검사를 포함했다.

역할 프롬프트, Synthetic 데이터 생성, 사실 평가 규칙, 스케줄러의 목적함수 및 수명 지표는 기존 프로파일을 유지한다. CPU 검사 성공은 실제 자연어 사실성 정확도나 새로운 GPU 벤치마크 결과를 의미하지 않는다.
